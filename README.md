# Athletic Performance Intelligence Website

**[View live site →](https://serina-zou.github.io/Athletics-Performance-Intelligence/)**

Marketing website for Athletic Performance Intelligence, MoodChanger's product for coaches and athletic organizations. The product uses FloBrain, the company's AI engine, to bring athletes' cognitive, behavioral and physiological data into one place.

Built during my UI/UX Design Internship at FloLabs Innovations Group (May–Sep 2026).

**My role:** Front-end development from Figma designs
**Built with:** A single self-contained `index.html` (images, fonts and scripts inlined), with no build step

The site reuses the hero, project card and application CTA components from the [MoodChanger](https://github.com/serina-zou/moodchanger) site.

## Run locally

Open `index.html` in any browser. It works offline.
